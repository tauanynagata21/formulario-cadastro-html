# Formulário de Cadastro em HTML

Projeto desenvolvido em aula para praticar elementos de formulário em HTML.

## Objetivo
Aprender a utilizar diferentes tipos de inputs e criar um formulário de cadastro básico.

## Elementos utilizados
- Inputs de texto, email e senha
- Inputs numéricos e de data
- Select (lista de estados)
- Radio buttons
- Textarea
- Botões de submit e reset

## Tecnologias utilizadas
- HTML5

## Observação
Projeto desenvolvido para aprendizado de formulários e entrada de dados em páginas web.
